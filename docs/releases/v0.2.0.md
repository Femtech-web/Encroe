**The studio shut down. The game didn't.** v0.2.0 takes Encroe from one game to five, from the command line to the
browser, and from NEAR to a second chain: a released world's items now leave the game, signed by a key nobody holds.

Site: https://encroe.vercel.app · For judges: https://encroe.vercel.app/judges ·
[JUDGES.md](https://github.com/Femtech-web/Encroe/blob/main/JUDGES.md)

## New in v0.2.0

- **Items on another chain, through NEAR Chain Signatures.** `contracts/encroe-items` (keyless,
  `encroe-items-ba9e16.testnet`) checks a player's claim against a released escrow's committed root and their game
  key's signature, then has NEAR's MPC network sign an EIP-712 claim. `EncroeItems` on Base Sepolia mints exactly
  those items, once. Recorded: two players' items minted; forged, inflated, live-escrow and repeated claims refused on
  NEAR and on Base ([items](https://github.com/Femtech-web/Encroe/blob/main/docs/results/items/README.md)). The claim
  panel is on `/revive`.
- **Five games, five languages.** Starhaul (Zig) and Orchard (Go, with TinyGo) join Embergate (Rust), Matchday (C++)
  and Neon City (C): sealed into factory escrows, verified green, each rebuilt byte for byte from source
  ([engines](https://github.com/Femtech-web/Encroe/blob/main/docs/results/escrow/engines/README.md)).
- **Starhaul in 3D.** A live three.js sector on `/play/starhaul`: click a belt to mine it; every pilot's ship flies
  where the sealed Zig core says they worked.
- **Seal from the browser.** `/studios/seal`: a studio seals, commits and verifies with three wallet signatures; the
  package key leaves the tab only encrypted to OutLayer's keystore. Recorded: Neon City's world, verified green
  ([browser-seal](https://github.com/Femtech-web/Encroe/blob/main/docs/results/escrow/browser-seal/README.md)).
- **An AI agent nobody wrote for Encroe.** Claude Code, unmodified, with only the site's MCP server, found a silent
  studio, inspected its escrow, released it and brought the game back with all 8 checks in 48 s. The key was published
  4.8 s after the release transaction, and the game was back 17.5 s after it
  ([the run](https://github.com/Femtech-web/Encroe/blob/main/docs/results/agent-runs/20261114-0843-release-and-revive/README.md)).
- **Every attack, every byte.** [docs/attacks.md](https://github.com/Femtech-web/Encroe/blob/main/docs/attacks.md):
  27 ways to cheat, what stops each and what it costs, 12 run live and refused;
  [docs/crypto-spec.md](https://github.com/Femtech-web/Encroe/blob/main/docs/crypto-spec.md): every format, each held
  by a test across two implementations; 110 property cases over generated worlds.
- **Faster and sturdier.** NEAR reads fall back across three public RPCs; the home page streams (first byte in about
  60 ms); game polling pauses in hidden tabs; cores are cached; an RPC outage no longer shows as a missing escrow.
- **Records.** Embergate's public world sealed by the studio workflow on CI (epoch 4, green); ember-3924 released by
  a watcher and opened, every hash matching.
- **Docs.** README rewritten; properties 16–20; trust and threat model for browser sealing and the handover;
  [hosting, designed](https://github.com/Femtech-web/Encroe/blob/main/docs/design/hosting.md).

## Check it yourself

```bash
make test                     # 31 Rust and 5 Solidity tests, and native-vs-wasm determinism of the verifier
cd web && npm ci && npm test  # 204 site tests, 110 of them property cases
scripts/build/cores.sh        # rebuilds the C++, C, Zig and Go cores: the same sha256 as each escrow's core_sha256
```

## Disclosed

- NEAR testnet and Base Sepolia only; no mainnet transaction was sent.
- Every recorded release follows a silence we caused; scripted players are labelled in each write-up.
- Base gas for the item token was paid from the author's other project's testnet relayer (Klear's).
- Two epochs are stranded and can never be verified (Embergate epoch 2, Neon City epoch 1); both causes are fixed
  and written up.
